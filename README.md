# Sara Beauty Parlour 💇‍♀️✨

A modern, full-stack luxury beauty parlour & salon web application designed with an aesthetic responsive UI, comprehensive service catalog, appointment booking, team showcase, reviews, and backend integration.

## 🚀 Tech Stack

- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Lucide Icons, Framer Motion
- **Backend**: Node.js, Express, TypeScript, Supabase Client / Database
- **Database**: Supabase (PostgreSQL with migration scripts & seeds)

## 📁 Project Structure

```
Sara Beauty Parlour/
├── frontend/      # React + TypeScript + Vite frontend client
├── backend/       # Express + TypeScript API server
└── supabase/      # Database migrations and seed SQL scripts
```

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
npm install
npm run dev
```
